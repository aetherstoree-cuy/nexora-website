## About NEXORA

**NEXORA** is a Minecraft hosting brand focused on making server hosting simple and accessible. Whether you're starting a small server with friends or building a growing community, NEXORA aims to provide a straightforward hosting experience.

Our goal is to deliver a clean, modern, and reliable experience for Minecraft server owners.

## Features

- **Minecraft Hosting** — hosting options for different server needs.
- **Java Edition Focus** — support for Java Edition server setups.
- **Simple Ordering** — contact our team through Discord to discuss an order.
- **Community Support** — get help with questions and hosting-related issues.
- **Modern Website** — a clean, responsive interface with NEXORA's dark futuristic branding.

4. Make your changes and test them before deploying.
