Taruh gambar utama di folder ini:
- logo.png       -> logo di navbar dan footer
- favicon.png    -> ikon kecil di tab browser (di samping domain). Ganti file ini dengan fotomu,
                    pakai nama yang sama (favicon.png), PNG persegi, sebaiknya 256x256 atau lebih.
- qr-discord.png -> QR Discord di kartu "Siap bikin server kamu?"
Sub-folder: plugin/ (ikon plugin di loop) dan paket/ (foto kartu jasa).
Setelah mengganti favicon.png, tekan Ctrl+F5 (hard refresh); browser kadang menyimpan ikon lama.
